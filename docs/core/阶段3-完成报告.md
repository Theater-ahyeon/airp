## 二、阶段 3 核心交付架构

1. **通用状态 Schema 与事件溯源（`src/core/types/schema.ts`、`src/core/state/state-manager.ts`）**：
   - 基于 Zod 定义通用状态值 `StateValueSchema`、操作原子 `StateOpSchema` 与卡级长期记忆模型 `CardLevelMemorySchema`；
   - `StateManager.projectState` 实现分支感知的状态投影与**物理遗忘语义**：当某分支被回退或遗忘时，属于被删除楼层的 `StateOp` 自动从派生状态中彻底排除。
2. **后台管家与四级降级阶梯（`src/core/butler/`）**：
   - 实现了四级降级阶梯执行与容错：
     - **Tier 1 (Tool Calling)**：主路径结构化 Tool Call 参数提取；
     - **Tier 2 (JSON Mode)**：模型原生 JSON Object 解析；
     - **Tier 3 (Prompt+Parse)**：带重试与正则提取的 Markdown Fenced JSON 解析；
     - **Tier 4 (Disabled)**：静默降级并显式上报，绝不让管家异常阻断前台对话。
   - **管家一致性协议**：`waitForFloorSettlement` 确保下一次 Prompt 组装严格等待紧邻前一楼管家状态操作结算完成。
   - **管家内置插件原则**：`ButlerHostABI` 明确约束管家只能吃公开的宿主接口（状态读取、状态操作追加、摘要更新），杜绝任何特权后门。
3. **摘要版本化懒重算与复盘（`src/core/memory/`）**：
   - `SummaryManager`：按 `branchId` 维护摘要版本，仅在楼层跨度增量达到阈值（如 10 楼）时触发重算；删分支即同步物理遗忘；
   - `SessionReviewConsolidator`：会话结束时提取高置信度核心事实，合并去重至长期卡级记忆（`CardLevelMemory`）。
4. **世界书双模检索（`src/core/worldbook/dual-mode-retriever.ts`）**：
   - 模型主动检索（Tool-search）优先 + 关键词兜底（Keyword fallback）协同；
   - 包含实时 Token 预算估算与优先级排序。
